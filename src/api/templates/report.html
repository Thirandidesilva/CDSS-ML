How To Read This Report

Severity is measured with an item response theory model and placed against an external reference population, so the level reflects where this dog sits relative to dogs in general. Phenotype describes the pattern of behaviour rather than its overall level, and its confidence shows how clearly the dog fits that pattern.

Where confidence is low, or where the severity estimate is too imprecise to act on, the case is flagged above for veterinary review rather than given a type-specific recommendation.

Important. Pawsitivity is a clinical decision support tool intended to assist, not replace, professional veterinary judgement. It is based on owner-reported behaviour and does not constitute a diagnosis. Severity levels, phenotype, and recommendations are provided to support a veterinary consultation. Please interpret this report in the context of a full clinical examination and history.
